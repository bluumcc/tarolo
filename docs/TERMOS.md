# Termos do jogo

| Termo | O que é |
|---|---|
| **Partida** | Do sentar na mesa até sair ou ser eliminado. Termo livre de menu e lobby ("partida encontrada"). |
| **Ritual** | Um ciclo completo: Preparação (Sacrifício e Profecia) e as 8 jogadas. No ranqueado repete igual. No torneio o blind sobe a cada Ritual ("Ritual 4"). |
| **Preparação** | Nome padrão da tela das duas etapas antes das jogadas. O nome da etapa vem como subtítulo. |
| **Sacrifício** | Etapa em que se escolhem 2 das 10 cartas para descartar. As cartas descartadas são as sacrificadas. |
| **Profecia** | Etapa em que se diz quantas jogadas vai ganhar (0 a 8) e se paga a entrada. O número também é a profecia. |
| **Jogada** | Cada aposta com uma carta lançada por jogador. Oito por Ritual (JOGADA 3 DE 8, os 8 dots). |
| **Aposta** | As fichas postas na jogada (termo universal do poker). |
| **Buy-in** | O valor pago para entrar no torneio ou sentar na mesa (antes "Inscrição" no menu do torneio). |
| **Ranqueada** | Grafia única (antes aparecia "Rankeada"). |

"Nível" ficou só no sentido de nível do jogador, e no Vanilla (cada mão). O degrau do torneio é o Ritual.
O Louco, o Trunfo (arcano maior) e os naipes (arcanos menores) mantêm os nomes das cartas.

## Cartas
**Arcano maior** = as 21 cartas numeradas (antes "Trunfo"). **Arcano menor** = as cartas dos 4 naipes (antes "carta de naipe comum").
**Naipe** continua sendo o grupo (Ouros, Paus, Copas, Espadas). O Louco mantém o nome. "Cortar" é jogar arcano maior sobre um naipe.
